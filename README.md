# PHP & MySQL Course Learning

This repository contains practical examples and exercises from the Web Application Development (PHP & MySQL) course.

## Requirements

- XAMPP

## Run Locally

1. Place this repository inside `C:\xampp\htdocs\`.
2. Start **Apache** and **MySQL** from XAMPP.
3. Open any lesson folder in your browser, for example:

`http://localhost/php-mysql-course/lesson-01-intro/`
